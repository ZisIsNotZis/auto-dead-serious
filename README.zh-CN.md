## 这是什么

Auto Dead Serious 把持续增长的实验目录变成可浏览的作品集。每个子项目
保留自己的历史、测试、许可证、发布路径和未来愿景；本仓库只固定当前作品集所使用的准确版本。

**优势：** 一个入口发现全部作品，**不抹平任何历史**，并对文档、证据、发布、媒体和研究设定明确质量标准。

## 快速开始

```sh
git clone --recurse-submodules https://github.com/zisisnotzis/auto-dead-serious.git
cd auto-dead-serious
git submodule status
```

请按各子项目 README 的前置条件和命令运行；工具链由子项目自行负责。

## 严肃标准

- **可复现：** 版本、变更记录、命令和带日期的证据齐全。
- **易理解：** 双语产品 README、紧凑文档、诚实状态。
- **可展示：** 有用的公开项目准备截图、录屏和人工审核的 Bilibili 方案；有创新的项目准备正式论文材料。
- **可维护：** 欢迎 Issue 和 PR；智能代理可以协助，人类保留审核合并权。

## 范围与非目标

这是索引和发布边界，不是单体仓库、统一构建系统，也不保证每个实验都已达到生产级。生成依赖、凭据、私密材料和未经审核的媒体不应提交到这里。

## 未来愿景 🛰️

最终希望它成为一个真正可用的想法目录：每个有用项目都能在几分钟内试用，每个创新都有可测证据，每个成熟应用都有用户可安装的发布版本。新项目按 [AGENTS.md](AGENTS.md) 加入。

## 贡献

请向对应子项目提交 Issue 或 PR；作品集成员关系和规范问题提交到本仓库。描述受影响路径、证据和验证命令。代理可以协助分诊、研究、测试、文档和实现；维护者负责审核与合并。

本汇总仓库的规范和原创材料使用 AGPL-3.0-only。子项目保留各自许可证，复用前请逐一检查。
