# Catalogue
Authored document owning the parent repository's curation criteria.
## Membership
User-stated criterion: a project qualifies through creativity OR current or credible expected usefulness without merely repeating an existing open-source project OR substantial work proving it is trying.
Approved interpretation: meaningful differentiation can qualify a useful project despite existing alternatives; substantial work requires meaningful implementation or experimental evidence relative to scope, not file/commit counts, a large codebase or mandatory test-suite presence.
Membership and prominence are separate decisions; qualifying for retention does not automatically justify featuring a project.
## Assessment
The user approved finalizing the corrected rubric and assessing the full collection after the bounded pilot and calibration; this is an investigation mandate, not authority to remove anything or modify children.
Assess creativity, current usefulness, expected usefulness, impl progress and presentability independently; ../method/catalogue.md owns anchors, evidence conventions and verdict derivation. No overall average decides membership.
Expected usefulness rates value conditional on completing an explicitly stated intended scope; delivery likelihood and evidence confidence are separate, not hidden penalties for unfinished work or archive status.
Creativity considers both novelty and interestingness; bounded public research can establish overlap, not global originality or equivalence of implementations.
Each project needs a short description, distinctive contribution, evidence, membership reason and next decisive step; runtime verification, source inspection and forecast must remain distinguishable.
## Boundaries
Authorized scope is full-collection assessment and membership recommendations, preserving private information and pre-existing work; no installs, project execution, README modification, submodule removal, cleanup, child repairs, remote changes or published-history rewriting are included.
Removal requires a separately approved operation preserving unique work, local modifications, unpushed commits and valuable untracked files.
The README presentation remains provisional: an authored front door and generated showcase linking to an evidence-backed full catalogue.
