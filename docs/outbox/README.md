# Outbox

Messages to the person. One file each, first lines `kind:`, `spend:`, `from:`, then the question, then `## effort` with what was tried and why each path is closed.

`tools/needs.py` renders `docs/needs-you.md` from this directory. Reading deletes a message; deletion is the only receipt.

Nothing about a project is written here except by reference: a question about a project stays in that project's directory, and what arrives here names it.
