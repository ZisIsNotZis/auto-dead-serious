## Top 5 by value

1. `fat_kakeya_needle/docs/methodology.md:47-50` (+ `docs/philosophy.md:41-43`) - the optimizer optimizes the evaluator, not the problem: a target function sampling at `n_theta=40` under-covered by 21% at ε=0.005 and produced two retracted conclusions from one root cause. No general rule currently says to validate a metric's resolution against its own parameter before trusting any search that consumes it.
2. `raid_calc/.scratch/01-raid-calc/issues/13-build-bundle.md:26` - the unit suite was green while the built artefact never booted, and the smoke test that found five P0 bugs had been deferred to the user as "no browser in agent env". The policy's gate rules must say the artefact the user receives is what gets exercised.
3. `ra2/.scratch/remaining-coverage-audit.md:36-38` - the design audit passed because all the stale IDs were self-consistently stale; a reference check that resolves references against each other measures nothing. The policy needs "resolve against the canonical registry, never against mutual consistency".
4. `dojo/.scratch/stranger-methodology-demo-work.md:33` - a resumed agent enforced an outdated copy of the governing policy and refused authorised work, calling it a recovery judgement error. Nothing in the policy says the rules must be re-read at resume and that an inherited copy is not authority.
5. `fat_kakeya_needle/docs/methodology.md:13-17` (+ `docs/philosophy.md:33-34`) - identical configs differed by up to 46% across seeds and the good basin appeared in one of three or four, so any single-seed number is meaningless: results must be a min over ≥3 fresh seeds with the hit-rate reported.
