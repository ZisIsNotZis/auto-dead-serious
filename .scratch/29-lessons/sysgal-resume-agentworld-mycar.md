# Lessons mined from sys_gal, resume_private, agentworld, mycar

Slug: `sysgal-resume-agentworld-mycar`. Read once each: the four project roots' `*.md`, `docs/`, `.scratch/`
ticket and spec files, plus `/home/z/vibe/AGENTS.md` (240 lines) and `CONTRACT.md`. Nothing was written
inside any project. Method note (disclosed because it was not intended): an early `ls docs` / `ls .scratch`
was run from `/home/z/vibe` instead of inside a project, so I saw the directory listing of
`/home/z/vibe/.scratch` (names only) before correcting the path; no file there except `CONTRACT.md` was opened,
and no finding below depends on it. Absence claims below ("does not exist") were checked with `test -e`
against the citing document's own directory.

Judgement key: **policy candidate** = rule the general policy looks like it lacks; **already covered by X**;
**project-specific**. "Inference:" marks my reading rather than the file's words.

## sys_gal

- [project rule] `契约失效时请勿喂猫/AGENTS.md:13,15` - "reaching `world_stops` alone never proves the trajectory is healthy or complete"; "Statistics may support an observation, but they are never the conclusion" - a green automated end-of-run gate is treated as a readiness signal only, never as the verdict; the report must lead with observed behaviour - **policy candidate** (the policy's proof section demands evidence, but never says an automated gate that fired is not a result; same shape as agentworld's "her VS1 hermetic PASS ≠ accepted").
- [project rule] `AGENTS.md#Pre-run gate` + `### v4 seed self-consistency gate` - the historical failures "v1/v2 audits, v3 issues 01-09, large-run deadlocks" are each mapped to a guarding test in `harness/tests/test_historical_failures.py`, and any new in-world name not registered in `world/manifest.yml` fails `scripts/seed_lint.py` by design - **policy candidate**: an existing failure is not fixed until a test named after it can fail again, and prose names must resolve to registered entities (the enforcement half of `one_name_one_thing`/`references_resolve`).
- [pitfall] `.scratch/v4-first-day/issues/53-stall-budget-and-hung-decision-pins-the-run.md#根因` - "`self._stall_seconds` 是**累积等待**（`+= elapsed`，从不重置）… 它衡量的不是'连续无进展'，而是一个健康但慢的运行也会触顶；同时它把'真挂死'和'总等待多'混成一个信号"; the earlier remedy "stall 预算放宽到 60%" is called 治标 - one never-returning decision pinned the scheduler (`target = min(self._inflight.values())` constant), freezing sim time at 11:32 for 15 minutes - **policy candidate**: a guard that measures cumulative rather than continuous progress cannot tell healthy-slow from hung, and widening its threshold is treating the symptom.
- [know-how] `.scratch/v4-first-day/issues/54-provider-request-has-no-wall-clock-bound.md#根因` - "`timeout` 是 **socket 级**：它约束'单次连接/单次 recv 的静默时长'，**不是整个请求的上界**；服务端只要持续滴流、或保持连接不断开，`response.read()` 就能一直不返回"; the retry/deadline budget "只在**每次 attempt 的顶部**做" - **policy candidate**: a non-obvious library fact (an HTTP timeout is not a request bound) that an agent will not know unaided; verify a hang is bounded by the whole operation, not by a per-socket parameter.
- [pitfall] `.scratch/v4-first-day/issues/67-wall-deadline-starved-by-inflight-wait.md#影响` - "墙钟上限是**安全属性**（'无论如何 2 小时必须停'），被饿死意味着一个慢/抖动严重的运行可能远超预算，在无人值守时尤其危险"; the check sat in the outer loop while the inner wait loop held the turn - **policy candidate**: a stop condition that can only be evaluated between blocking waits is not a bound; put it inside every wait that can be long.
- [pitfall] `.scratch/v4-first-day/issues/68-trace-private-state-misleads-reviewers.md##现象` - "`private_state.memories` 是**遗留字段**，v4 不再使用，却在轨迹里保持为空且无任何说明 … 复盘者（人）与 reviewer（子代理）都会据它得出**错误的 P1**" - multiple independent reviewers reached the same wrong root cause from an unmarked stale field - **policy candidate**: an obsolete field or file left in place without a marker is read as data; the reader cannot tell "empty" from "not used" (converges with resume_private's `chengzhi.json`).
- [pitfall] `.scratch/v4-first-day/issues/51-sync-runner-vs-async-engine-drift.md##风险` - "两条路径各自维护一套 CAST 与监测逻辑，历史上已多次出现'修了 AsyncEngine、同步路径仍旧'的情况"; "`dry_run` 是我们每次改动都要过的门禁；若同步路径行为与生产路径偏离，门禁的'绿'就不能代表生产行为，等于**用一个廉价替身验证生产核心**" - **policy candidate**: a cheap stand-in that gates is evidence about itself, not about the production path, until equivalence is tested; the ticket's own acceptance direction is "抽出共享实现 … 而不是再抄一遍".
- [pitfall] `.scratch/v4-first-day/issues/52-move-leave-vs-present-contradiction.md##影响` - "`move` 在**提交时**就广播 `leave` 事件，而 `ActorState.location` 要到该段行程**完成**才更新 … 复盘读轨迹时，'在场'一栏不可信，人工审阅会被误导（本次多名 reviewer 都踩到）"; 8 recorded instances - **policy candidate**: one fact with two representations updated on different schedules produces a contradiction that reviewers then reason from; the two must share one resolution point (the ticket's fix direction: "抽出**单一在场函数**").

## mycar

- [project rule] `AGENTS.md:9` (rule 5) and `WORKSPACE.md` (v12 structure conventions) - "**校验与画面同源**：任何判据必须引用绘制用同一个 builder 的输出。禁止第二份数学（v11 的 30+ 处错误的根因）"; "新增几何量时：先加进 `build()` 的 `d`，再让绘制与判据都读它；**禁止**在绘制或判据里重算第二份" - a check that recomputes the quantity it checks contradicts the picture it checks, and the two then drift silently: this root cause produced "v11 的 30+ 处错误" and the whole v12 engine rewrite - **policy candidate**: the strongest form of one-home for derived values - a verification must consume the same computed output the artifact is made of, never a second implementation of the same formula (sys_gal's ticket 46/51 are the same defect in a simulation).

## Top 5 by value

1. **mycar AGENTS.md rule 5 / the two-maths defect** - a check must consume the same computed value the deliverable is drawn from; a second implementation of the same formula is how 30+ errors accumulated and why an entire engine had to be rewritten. The policy speaks of one home for facts but never for *derived numbers inside an artefact*.
2. **mycar AGENTS.md rule 10 - stop when you cannot see the artefact** - the sharpest form of "unverified is not PASS": a visual verdict produced without the image is false evidence, the correct move is to halt the slice and say so, and number-crunching cannot be substituted for looking.
3. **agentworld Makefile - derived bounds plus a failure probe for every gate** - timeouts must come from measured compute with a stated margin (a bound below the real cost manufactures a false red; one that never fires is not a bound), and each gate needs a probe proving it rejects a broken input. Three of the four projects paid for this lesson separately (sys_gal's historical-failure ledger, the JWT the old scan could not see).
4. **agentworld's tautology (supply 16 = burn 16) and mycar's 1-in-20,000 feasible set** - before spending on a comparison, prove the arms can differ; when the design has only one passing solution in twenty thousand samples, suspect the criteria rather than the design. Both are cheap checks that each project performed after, not before, four to eleven tickets of work.
5. **agentworld's effort-fraction audit** - after ~109 commits, 89% of the work had gone to a substrate whose last five tickets measured the authors' own constants, while the differentiating mechanism had 0 tickets and 0 lines; the policy demands that each requirement trace to the goal but never measures where the effort actually went. This is the most expensive lesson in the set and the only one with a short check.
