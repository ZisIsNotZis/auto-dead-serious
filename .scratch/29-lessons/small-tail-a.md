# small-tail-a — lessons from 17 small archive repositories

Scope: `ygo`, `xywdisk`, `uv`, `treui`, `tok`, `seq_autoenc`, `ringsvr`, `retnet`, `nn`,
`neuronloop`, `myzcopy`, `myygo`, `myminio2`, `myminio`, `lmlayer`, `knowledge_net`, `jpi.fe`.
Every project has exactly one `README.md` plus `docs/project-status.md` (plus a few source files);
eight of the seventeen also carry the same generated status stub. Read-only; the policy
`/home/z/vibe/AGENTS.md` was read once and neither `AGENTS.yaml` nor anything else at the top of
`/home/z/vibe/` was opened.

Judgement keys: **policy candidate** = the general policy looks like it lacks this;
**already covered by X** = naming the rule that governs it; **project-specific**.

## Top 5 by value

1. **Publication boundary (licence + third-party data + sanitisation).** No policy rule covers what to do when work leaves the private machine: 14 of 17 projects had to decide a licence ("none → all rights reserved") and separate embedded third-party data (Konami card text, a DINOv2 GGUF, a public-domain MD5 snippet), and three separate projects had to redact a key, a token or a whole employer notebook before the copy could be published — a rule with a stated scan (keys, employer material, absolute user paths) and a documented delta from the original would stop an agent re-deriving it project by project.
2. **Archive fidelity: kept-on-purpose files and names.** `retnet/nn.py` is the published `cznn` and must not be rewritten, `neuronloop` keeps a divergent fork on purpose, `myzcopy/filesvr.py` is a deliberately non-functional stub, `nn.old.py`/`rev.old.py` are reloaded by cells — every one of these needs a written "kept on purpose" or the policy's own "hard-delete the dead fact" and "one name for one thing" instincts will destroy the archive, so the policy needs an explicit archive/SSOT mode.
3. **Containment before running an archived artefact.** `xywdisk/disk.py` actuates real hardware over a private LAN, `seq_autoenc`'s notebooks write generated binaries into `../nlpdat/` outside the tree, and `ringsvr` binds `INADDR_ANY:8000`; reading a script's write surface and running it in a scratch directory is not covered by any rule today.
4. **Never transcribe code or config out of a rendered document.** `myminio/docs/project-status.md` records that the archived `docker-compose.yml` was invalid YAML because a copy/paste from a rendered page injected spaces into every `command:` and `volumes:` line, and only running `docker compose config` revealed it — an agent would not guess this and the check is cheap.
5. **Status vocabulary and template leakage.** One label cannot carry both toolchain age and completeness: `tok` had to invent "`deprecated (2025 era)` in tone" plus "`archive_only` for migration", and the shared generated stub left the literal placeholder "(`deprecated (<year> era) - kept as an archive` where applicable)" in 8 of 17 repos, so status must be a fixed set of orthogonal facts (age, maintenance, completeness, runnability) with no free-text placeholder surviving into a shipped file.
