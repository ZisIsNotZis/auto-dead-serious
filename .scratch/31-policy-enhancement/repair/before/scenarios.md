# Scenario matrix — semantic self-check, not independent review or runtime proof
This is a bounded set of representative stories, not a claim to cover all possible stories. Each row is a deliberate judgement check: its expected decision must be derivable from the owning rules in the final generated policy. The mechanical harness checks only that cited owners exist in the rendered view. Normal, failure, unavailable-evidence, interruption and resource-constrained paths are covered across each requested work family; resource counterexamples are separate below. Authority refers to the existing discussion/advance and high-risk contracts; techniques grant no additional authority.

## Self-check findings and limits
The expected actions above are consistent with the final scoped text in worker judgement. This is not an independent verdict. Checks settle key existence/render/schema/layout, not semantic uniqueness or whether an agent will reliably follow the policy. No resource allocator, cgroup/quota binding, OOM containment, GPU isolation, multi-requester race, live crash recovery, AI experiment, performance benchmark, phase automation or user-facing milestone was implemented or exercised. No universal coverage/infallibility claim is made. Parent must obtain fresh independent review at the final hashes before claiming acceptance.
